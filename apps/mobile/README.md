# Hernandez Pass — App iOS (Expo)

App nativa App Store para staff/admin ligero. White-label por negocio (código + branding).

## Desarrollo

```bash
npm install
EXPO_PUBLIC_API_BASE_URL=https://pass.edgardohernandez.com npm start
```

Presiona `i` para simulador iOS.

## Login

1. Código del negocio (slug), ej. `hernandez`
2. Email autorizado como staff
3. Magic link → abre `hernandezpass://auth?token=...`
